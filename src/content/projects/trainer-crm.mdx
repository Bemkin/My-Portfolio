### How it works

Both apps talk directly to Supabase. Business rules that need secrets, such as sending email or SMS, run in Deno Edge Functions.

```
┌──────────────────┐                          ┌──────────────────────────┐
│ Web app          │ ──┐                  ┌─▶ │ Postgres + RLS           │
│ Vite + React     │   │   ┌──────────┐   │   │ org-scoped tables        │
└──────────────────┘   ├─▶ │ Supabase │ ──┤   └──────────────────────────┘
┌──────────────────┐   │   │ client   │   │   ┌──────────────────────────┐
│ Mobile app       │ ──┘   └──────────┘   └─▶ │ Edge Functions           │
│ Expo + NativeWind│                          │ email, SMS, invites      │
└──────────────────┘                          └──────────────────────────┘
```

### 1. Clients and programs

- Trainers keep a client list and build workout programs made of workouts and ordered exercises. Programs can be duplicated and assigned to or removed from clients.
- Exercises come from the trainer's own library or from the ExerciseDB API, with results cached in the browser for an hour.

### 2. Sessions, progress and habits

- Appointments are scheduled per client. A "send all reminders" action calls an Edge Function that emails the client through Resend, or texts them through Twilio when SMS is configured, and marks the appointment as reminded.
- Progress entries, workout logs and habits are tracked per client.

### 3. Billing and messaging

- Trainers create invoices, preview and print them, record payments (cash, card, bank transfer, cheque or other) and mark invoices paid.
- Client messages are sent by email from an Edge Function, and the inbox updates live through a Supabase Realtime channel.

### 4. Organizations and security

- On signup a trainer creates an organization and becomes its owner. Functional tables carry an organization ID, and row-level security policies limit every read and write to the user's organization.
- The move to multi-tenancy shipped with backfill and rollback migrations, and the repo includes SQL scripts that check policy isolation.

### Engineering notes

- **Mobile:** the Expo 54 / React Native app uses NativeWind and mirrors the web modules: dashboard, clients, appointments, workouts, progress, habits, invoices and messages.
- **Localisation:** a shared translation file covers English and Amharic, and dates can be picked in the Ethiopian calendar.
- **Status:** reminders are sent when the trainer triggers them; scheduled sending is not built yet.
