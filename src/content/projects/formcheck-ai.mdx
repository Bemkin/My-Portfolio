### How it works

FormCheck has two halves: a React front end that does pose tracking in the browser, and a Python backend for heavier analysis.

```
┌────────────────────┐     ┌────────────────────────┐     ┌──────────────────────┐
│ Webcam / upload    │ ──▶ │ MediaPipe Pose         │ ──▶ │ Joint-angle rules    │
│ (React + Vite)     │     │ 33 landmarks, overlay  │     │ score + coaching cue │
└─────────┬──────────┘     └────────────────────────┘     └──────────────────────┘
          │
          ▼
┌────────────────────┐     ┌────────────────────────┐
│ FastAPI backend    │ ──▶ │ /ws/squat: rules + RF  │
│ (local, port 8000) │     │ /analyze-video: Gemini │
└────────────────────┘     └────────────────────────┘
```

### 1. Live pose tracking

- MediaPipe Pose runs in the browser on a 1280×720 webcam stream and draws the skeleton onto a canvas.
- Each frame goes to an exercise-specific analyser. The squat check, for example, looks at average knee angle (target 70–110°), back alignment from ankle to hip to shoulder, and whether the knees travel past the toes.
- Each failed check deducts points and adds a specific cue, so the score always comes with a reason.
- A rep counter watches the knee angle: below 100° counts as down, back above 150° completes the rep.

### 2. Squat classifier

- A training script extracts MediaPipe keypoints from labelled correct and incorrect squat images and trains a scikit-learn RandomForest (100 trees) on 325 samples.
- Over the WebSocket, the backend runs the classifier on each frame, averages its confidence with the rule score, and flags form the model thinks is wrong.

### 3. Video analysis with Gemini

- Uploaded videos go to a FastAPI endpoint that sends them to Gemini 2.5 Flash through the Files API, with a prompt that asks for a strict JSON schema: average score, total reps, duration, issues, coaching feedback and key metrics.
- If the upload fails, the backend extracts up to 12 keyframes and sends those instead. With no API key set, it falls back to frame-by-frame MediaPipe analysis with OpenCV.
- These endpoints currently run on a local backend, so they work in development rather than on the deployed site.

### Engineering notes

- **Accounts:** Supabase email auth, with a signup trigger that creates a profile and row-level security policies that limit each user to their own rows.
- **Localisation:** a language context switches the interface between English and Amharic.
- **Status:** the project started from a Lovable scaffold. The public site shows a Coming Soon page with a beta preview of the workout studio, and the live camera mode is behind an in-app Premium toggle that is not tied to payments yet.
