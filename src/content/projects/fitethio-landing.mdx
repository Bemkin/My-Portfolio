### About the project

FitEthio is a CRM concept for personal trainers. This repository is its pre-launch landing page: the CRM itself is not built here, so features like client tracking and payments are described in copy, not implemented.

```
┌────────────────────┐   ┌────────────────────┐   ┌────────────────────┐
│ Preloader          │──▶│ Hero (600vh pin)   │──▶│ Phone mockup pin   │
│ 193 images, real % │   │ 192-frame canvas   │   │ slides app screens │
└────────────────────┘   └────────────────────┘   └─────────┬──────────┘
                                                            ▼
                         ┌────────────────────┐   ┌────────────────────┐
                         │ Waitlist CTA       │◀──│ Feature cards ·    │
                         │ magnetic button    │   │ integrations       │
                         └────────────────────┘   └────────────────────┘
```

### 1. Canvas hero sequence

- The hero is a 600vh section whose inner wrapper is pinned with GSAP ScrollTrigger.
- A scrubbed timeline moves through 192 pre-rendered JPG frames (an AI-generated laptop and dashboard animation) and draws each one on a full-screen canvas. Cover-fit math crops the frame to the viewport, and the canvas redraws on resize.
- Three headlines fade in and out at set points on the same timeline, and the hero fades out at the end so the next section takes over cleanly.

### 2. Preloader

- Every frame, plus the phone frame image, is preloaded with `new Image()`, and each load or error raises the progress count.
- The preloader eases its on-screen number toward the real progress and only exits at 100%. It then refreshes ScrollTrigger so pin positions are measured after all images have loaded.

### 3. Sections below the hero

- **Phone mockup:** a pinned section holds for three screen heights of scrolling and slides a track of app screens across an iPhone frame.
- **Feature cards:** three cards whose radial glow follows the mouse through CSS custom properties, revealed with a staggered Framer Motion animation.
- **Integrations and reviews:** an integrations graphic and a scrolling review strip. The reviews are placeholder copy for the concept, not real customer testimonials.

### 4. Waitlist call to action

- The "Join Waitlist" button in the nav scrolls to the CTA and dispatches an `open-waitlist-form` event, which expands the form and focuses the email field.
- The CTA button pulls toward the cursor using spring motion values, and the effect is turned off on touch devices.
- Submitting the form checks the email and shows a confirmation state. Nothing is stored or sent yet; connecting it to an email list is the next step.

### Engineering notes

- **Stack:** Next.js 16.2, React 19.2, TypeScript, Tailwind CSS v4, GSAP 3 with ScrollTrigger and Framer Motion.
- **Cleanup:** ScrollTrigger instances, resize listeners and intervals are removed when components unmount.
