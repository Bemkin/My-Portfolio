### How it works

CoachTrack ET is a static site (one HTML file, one script, one stylesheet) that opens inside Telegram as a Mini App. All data lives in the phone's localStorage, and Google Sheets sync is optional.

```
┌──────────────────┐     ┌───────────────────────┐     ┌──────────────────────┐
│ Pitch-side       │ ──▶ │ Session form          │ ──▶ │ Timesheet            │
│ stopwatch        │     │ start, end, decimal   │     │ (localStorage)       │
│ (localStorage)   │     │ hours, attendance     │     │ + rain-day rows      │
└──────────────────┘     └───────────────────────┘     └──────────┬───────────┘
                                                                  │
                         ┌────────────────────────────────────────┼───────────┐
                         ▼                     ▼                  ▼
              ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
              │ ETB statement    │  │ CSV export       │  │ Apps Script      │
              │ → Telegram share │  │ (8 columns)      │  │ → Google Sheet   │
              └──────────────────┘  └──────────────────┘  └──────────────────┘
```

### 1. Pitch-side stopwatch

- **Start Practice** records the start timestamp. Pause and resume handle water breaks by adding up the time that has passed.
- The running timer is written to localStorage on every change and restored when the app reopens, so a phone call, closing Telegram or a reload does not lose the session.
- **Finish & Log** rounds to the nearest minute and opens the session form pre-filled with start time, end time and decimal hours (for example 14:20 to 17:50 is 3.50 hrs).

### 2. Timesheet and rain days

- Sessions can also be added or edited by hand; the form previews decimal hours from the start and end times and handles sessions that cross midnight.
- **Log Rain / Cancellation** adds a NO PRACTICE row with zero hours and zero attendance, a reason (Rain, Pitch Flooded, Holiday, Coach Unavailable) and an optional note.
- Filter chips switch between all, completed and cancelled entries.

### 3. ETB billing and parent statement

- The earnings view totals completed sessions, pitch hours and fees as `sessions × attendance × rate per kid` (for example 6 × 4 × 1,000 ETB = 24,000 ETB). Attendance is the average across completed sessions, rounded to a whole number.
- The statement lists sessions, rain days, hours, rate and total due, plus the coach's Telebirr number and CBE account from Settings.
- **Share to Telegram** opens Telegram's share sheet with the statement so the coach can pick the parent group, and **Copy Summary Text** puts it on the clipboard.

### 4. Export and Google Sheets

- **Export CSV** downloads the timesheet with the original sheet's columns: #, Date, Day, Start Time, End Time, Duration (hrs), Session?, Notes.
- For live sync, the coach pastes `google_sheets_sync.gs` into their sheet's Apps Script editor and deploys it as a web app. Each new session or rain day is posted to that URL and appended as a row, and a Test button pings it from Settings.

### Engineering notes

- **No dependencies:** vanilla JavaScript, HTML and CSS with only Telegram's WebApp script, so it can be hosted on any static host and registered as a Mini App through @BotFather.
- **Telegram integration:** it uses the WebApp API for haptic feedback and the share link, and falls back to a normal browser tab outside Telegram.
- **First run:** a four-step wizard collects the coach's name, class size, rate per kid and payment details.
- **Safety:** user-entered notes are HTML-escaped before rendering, and CSV fields are quoted with embedded quotes escaped.
- **Installable:** a web app manifest lets it be added to the home screen as a standalone portrait app.
