### About the project

This is an unsolicited redesign concept for **Express Transport & Logistics (Express PTL)**, a heavy-haulage and freight carrier working the Djibouti–Addis Ababa corridor. It is deployed on Vercel as a demo; the client has not adopted it.

The site presents the company's own figures as content: 76 company-owned prime movers, 2,916 MT of lift capacity, operations since 2013, a 910 km Djibouti–Addis corridor and AEO customs clearance. These are statements about the client, not engineering measurements.

**Design credit:** motion and layout patterns (preloader, page curtain, reading-scrub text) were studied from mvplogistics.eu and rebuilt from scratch in Next.js, React and Framer Motion.

```
┌───────────────────────┐   ┌───────────────────────┐   ┌───────────────────────┐
│ Home                  │   │ Operations hub        │   │ About / Services /    │
│ Preloader → sticky    │   │ Fleet · Corridors ·   │   │ Contact               │
│ video · reading scrub │   │ WFP data · Estimator  │   │ Per-page metadata     │
└───────────┬───────────┘   └───────────┬───────────┘   └───────────┬───────────┘
            └──────────── Lenis smooth scroll + page curtain ────────┘
```

### 1. Intro and video backdrop

- The preloader counts from 0 to 100% over 2.2 seconds, then expands into the hero video.
- Whether the intro has played is stored under the `express_ptl_preloader_seen` sessionStorage key and read through `useSyncExternalStore`, so it plays once per session and server and client markup stay in sync.
- Background videos sit in sticky 100vh layers behind the scrolling content. A small video component forces muted inline playback, shows the poster until playback starts and retries on the first touch or scroll, which keeps Safari from showing its play button in Low Power Mode.

### 2. Motion system

- **Lenis** runs one instance with a 1.2 s duration. A ResizeObserver keeps scroll bounds correct, the scroll position resets on route change, and modals pause and resume Lenis while open.
- **Reading-scrub text** splits a paragraph into words and maps each word's opacity to scroll progress with Framer Motion.
- **Page curtain:** internal links trigger a two-layer curtain that covers the viewport, navigates, then reveals the new page.
- The navbar hides and shows based on Lenis scroll direction.

### 3. Freight estimator (client-side)

- Inputs: origin port or hub, destination dry port or industrial park, cargo class, tonnage (1–150 MT) and an AEO customs toggle (+$350 flat).
- Outputs: a transit window (for example 3–5 days from Djibouti to Addis Ababa), an indicative price from per-ton rates and cargo multipliers, the number of trucks (one per 40 MT) and the suggested equipment type.
- The rates are illustrative values hard-coded in the component, not live tariffs. The "request quote" form validates required fields and shows a confirmation, but nothing is sent to a server.

### 4. Operations content

- **Fleet:** four vehicle types (corridor prime mover, modular multi-axle lowbed, container rig, bulk agri-carrier) with capacity notes and highlights.
- **Corridors:** Djibouti, Berbera, Moyale and Metema routes, each with distance, transit time, border post and checkpoint list in a tabbed view.
- **UN WFP records:** year-by-year cargo and container tables for 2022–2026, totalling 158,636 MT and 2,188 containers. The hard-coded totals match the row sums.

### Engineering notes

- **Stack:** Next.js 16.3, React 19.2, TypeScript, Tailwind CSS v4, Framer Motion, Lenis and Lucide icons.
- **Routing:** five pages (Home, About, Services, Operations, Contact). `/calculator`, `/fleet` and `/corridors` redirect to anchors on the Operations page.
- **SEO:** each page exports its own metadata, with OpenGraph and Twitter tags in the root layout.
- **Fonts:** Bebas Neue for headlines, Barlow Condensed for technical labels, Outfit for navigation and Plus Jakarta Sans for body text, loaded with `next/font`.
