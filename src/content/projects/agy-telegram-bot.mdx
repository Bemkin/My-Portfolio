### How it works

The bot runs on the same laptop as the coding agent. Telegram is reached over long polling, so the phone talks to the bot without the laptop accepting incoming connections for the chat itself.

```
┌──────────────────┐     ┌────────────────────────┐     ┌──────────────────────┐
│ Telegram (phone) │ ──▶ │ python-telegram-bot    │ ──▶ │ Google Antigravity   │
│ commands, voice  │     │ long polling,          │     │ agent in the project │
│ Mini App         │     │ user-ID allowlist      │     │ folder (Gemini)      │
└──────────────────┘     └───────────┬────────────┘     └──────────────────────┘
                                     │
                                     ▼
┌──────────────────┐     ┌────────────────────────┐     ┌──────────────────────┐
│ Cloudflare       │ ◀── │ Dev server manager     │ ──▶ │ Playwright           │
│ quick tunnel     │     │ start, stop, logs      │     │ mobile / desktop PNG │
└──────────────────┘     └────────────────────────┘     └──────────────────────┘
```

### 1. Talking to the agent

- Each chat message goes to a long-lived Antigravity agent session with mobile-friendly system instructions, so the agent remembers context across messages until `/reset`.
- An `asyncio.Lock` serialises requests, so messages sent in quick succession are queued instead of colliding.
- If the agent's connection drops, the bridge restarts the session and retries.

### 2. Planning before editing

- In planning mode, every prompt is wrapped with instructions to read the codebase and draft a plan without editing files.
- `/plan` saves the agent's plan to `.agent/plans/implementation_plan.md`, keeps a timestamped copy in an archive folder, and replies with an **Approve & Execute** button.
- Approving switches the agent to action mode and runs the plan; approving from the Mini App also saves a walkthrough of what was done. The guardrail is instruction-based: the agent's tools themselves are not blocked.

### 3. Model fallback

- The default model is `gemini-3.7-flash`. When a request fails with a 429, `RESOURCE_EXHAUSTED` or quota error, the bot switches to `gemini-3.5-flash-lite` and retries the message.
- Switching restarts the agent session, and further rate-limit errors on the fallback model are retried after a 12-second wait, up to two times.

### 4. Dev server, tunnels and previews

- `/dev` detects the start command for the project, runs it, keeps the output and shows the latest log lines on request.
- `/tunnel` launches `cloudflared` for a public HTTPS URL to a local port; `/tunnel stop` closes it.
- `/preview` opens the local app in headless Chromium and sends a screenshot at phone or desktop size.

### 5. Mission Control Mini App

- `/app` serves a FastAPI backend and a vanilla JS front end through a Cloudflare tunnel and opens it inside Telegram.
- Tabs cover a status dashboard, chat, plans and walkthroughs, change history, Git diffs and dev server logs. The page refreshes its status by polling every 3.5 seconds.
- Because the tunnel URL is public, every `/api` request must carry the Mini App's Telegram-signed `initData`. The server checks its HMAC signature against the bot token, rejects data older than 24 hours and only accepts the configured user. No CORS headers are sent, so other websites cannot call the API, and the live preview image is fetched with the same auth.

### Engineering notes

- **Access control:** every Telegram command and button handler is wrapped in an `authorized_only` check against one configured user ID, and the Mini App API verifies Telegram-signed `initData` for that same user on every request. Anything else is rejected and logged.
- **Auditability:** prompts, responses and the files they mention are logged to Markdown and `logs/history.json`, and `/audit` shows recent activity.
- **Quality:** 25 `unittest` tests cover the agent bridge, audit logger, message formatter, plan manager and the FastAPI endpoints, including missing, forged, expired, tampered and wrong-user `initData`, with a single runner script.
- **Open source:** MIT licence, a contributing guide, `.env.example`, and start scripts for Windows, macOS and Linux.
