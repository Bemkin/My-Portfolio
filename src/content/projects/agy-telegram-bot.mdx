### 📱 AGY Telegram Bot — Mobile AI Coding Agent Controller

**AGY Telegram Bot** bridges [Google Antigravity](https://antigravity.google) AI coding agents to Telegram, turning your smartphone into an executive mission control center. It enables software engineers to brainstorm architecture, approve structured plans, execute code modifications, control dev servers, and preview live interfaces from anywhere without exposing incoming firewall ports.

---

### 🌟 Key Architecture & Capabilities

1. **Google Antigravity Bridge & Safe Planning Mode**:
   - Integrates directly with the `google-antigravity` SDK and Gemini models.
   - Enforces a rigorous planning protocol: the agent explores codebase dependencies, formulates structured implementation plans, and presents diffs for mobile approval before modifying source code.

2. **Telegram Mini App (Mission Control Cockpit)**:
   - An embedded web IDE cockpit loaded directly within Telegram (`/app`).
   - Features real-time task progress tracking, terminal output streaming, active Cloudflare tunnel URLs, and interactive Git controls.

3. **Live Cloudflare Tunnels & Playwright Screenshots**:
   - Spawns instant, secure HTTPS public preview tunnels (`/tunnel`) on demand.
   - Uses headless Playwright to capture pixel-perfect mobile and desktop screenshots of the local development server (`/preview`) and pushes them directly into Telegram chat.

4. **Resilient Model Failover**:
   - Operates with `gemini-3.7-flash` for rapid execution, automatically failing over to `gemini-3.5-flash-lite` if rate limits or quota ceilings are approached, guaranteeing continuous uptime.
