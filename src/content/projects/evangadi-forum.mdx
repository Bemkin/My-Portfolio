A place for Evangadi students to ask questions and answer each other.

- Sign up and log in, with passwords hashed by bcrypt and sessions carried by JWT.
- Ask a question, browse all questions, open a question and post answers.
- Protected routes on the client, backed by an auth middleware on the API.
- MySQL access through parameterised queries.
- Responsive layout for mobile and desktop.

The backend lives in a separate repo: https://github.com/Bemkin/Evangadi-Api
