### 🤖 Cyborg Job Pipeline — Autonomous Sourcing & 1-Tap Executive Outreach

The **Cyborg Job Pipeline** eliminates the repetitive friction of high-signal job applications by pairing autonomous web intelligence with direct executive discovery and human-in-the-loop mobile execution.

```
┌─────────────────┐       ┌──────────────────────┐       ┌──────────────────────┐
│  Job Board API  │ ───▶  │ RocketReach API      │ ───▶  │ Google Gemini        │
│  RemoteOK & RSS │       │ Founder / CTO Lookup │       │ Context-Aware Pitch  │
└─────────────────┘       └──────────────────────┘       └──────────┬───────────┘
                                                                │
                                                                ▼
┌─────────────────┐       ┌──────────────────────┐       ┌──────────────────────┐
│ Verified Email  │ ◀───  │ Telegram Bot Daemon  │ ◀───  │ Interactive Alert    │
│ Delivered w/ CV │       │ One-Tap Dispatcher   │       │ [Send] [Edit] [Skip] │
└─────────────────┘       └──────────────────────┘       └──────────────────────┘
```

---

### 🌟 Core Architectural Components

1. **Autonomous Role Sourcing & Parsing**:
   - Continuously scans and filters remote engineering opportunities matching niche competencies: Agentic AI, TypeScript, Next.js, PostgreSQL, Supabase, and Offline-First Sync.
   - Filters out stale listings, agency spam, and salary-incompatible roles automatically.

2. **Executive Decision-Maker Discovery**:
   - Integrates with the **RocketReach API v2** to bypass generic `jobs@` black holes.
   - Searches hierarchical priority titles (**Founder**, **Co-Founder**, **CTO**, **VP of Engineering**) to pinpoint the exact technical leader building the team.

3. **SMTP Verification & Intelligence Enrichment**:
   - Performs SMTP mailbox validation on candidate corporate emails, verifying delivery viability before any outreach is initiated.

4. **Gemini Context-Aware Pitch Synthesis**:
   - Feeds the company's technical stack, stated problems, and mission into **Google Gemini** alongside Bemnet's verified production achievements (e.g. 15-tool agentic backend, 157 PostgreSQL migrations).
   - Produces a crisp, zero-fluff 4-sentence cold pitch articulating concrete value.

5. **Human-in-the-Loop 1-Tap Mobile Telegram Dispatch**:
   - Pushes an actionable Telegram message directly to your phone with interactive inline buttons:
     - `[ ✉️ Send Email ]` — Immediately sends the pitch from Gmail SMTP with the verified PDF resume attached.
     - `[ ✏️ Edit Draft ]` — Allows instant mobile reply with adjustments before dispatch.
     - `[ ❌ Skip ]` — Discards the lead and caches the domain.
