### About the project

Kaffa Roasters is a brand site concept for an Ethiopian specialty coffee label. It tells the origin story in chapters and ends in a concept subscription checkout. Details such as the 1,900m Kaffa highlands and 72-hour anaerobic fermentation are brand content shown on the gallery cards, not measured data.

```
┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
│ Hero sequence    │──▶│ Horizontal       │──▶│ Video portal     │──▶│ Flavor matrix    │
│ canvas, 192/96   │   │ gallery, 4 videos│   │ clip-path expand │   │ R3F jebena scene │
└──────────────────┘   └──────────────────┘   └──────────────────┘   └──────────────────┘
        ▲ Preloader waits for "hero", "gallery", "portal" and "matrix" ready events
```

### 1. Hero sequence

- A canvas-based sequencer scrubs through 1920×1080 JPG frames with GSAP ScrollTrigger, then fades out the canvas and masthead together.
- Phones load 96 frames instead of 192 to save memory and bandwidth, detected on the client so server and client markup stay in sync.
- The first frame is drawn as soon as it arrives, and the masthead typography animates in once it is visible.

### 2. Origin gallery and video portal

- On desktop the gallery pins and slides four video cards horizontally (Kaffa highlands, anaerobic processing, sun drying, the ceremony), with video parallax, giant background text and a progress bar. `gsap.matchMedia` swaps this for a plain vertical stack on mobile.
- An IntersectionObserver plays each video only while it is on screen and pauses it otherwise.
- The video portal grows from an inset rounded clip-path to full screen as you scroll, with separate tuning for desktop and mobile.

### 3. 3D flavor matrix

- A React Three Fiber canvas renders the jebena (traditional coffee pot) as a textured plane inside drei's `Float`, with `Sparkles` and a city environment map.
- Hovering or tapping a flavor profile (Floral & Citrus, Wild Berry & Wine, Stone Fruit & Spice) changes the section background and text colour, and `maath` eases the ambient light toward that profile's intensity.
- A GSAP scroll trigger adds a slight parallax to the 3D canvas.

### 4. Loading and scroll

- The preloader locks scrolling and waits for ready events from the hero, gallery, 3D section and video portal. It falls back after 30 seconds if any of them stall.
- Lenis provides smooth scrolling. ScrollTrigger ignores mobile resize events and limits refreshes to visibility, load and orientation changes, and `lagSmoothing` stops pinned scenes from jumping on iOS Chrome.

### 5. Concept checkout

- A cart button opens a spring-animated drawer with one subscription item and a particle burst on confirm. It is a simulated flow: there is no product catalogue, cart state or payment integration.

### Engineering notes

- **Stack:** Next.js 16.2, React 19.2, TypeScript, Tailwind CSS v4, GSAP 3, React Three Fiber 9, three.js, drei, maath, Lenis and Framer Motion.
- **Performance:** below-the-fold GSAP sections load through `next/dynamic`, while the hero stays synchronous for first paint.
- **Hosting:** Vercel headers set `Accept-Ranges` and revalidation for MP4 and WebM files.
- **SEO:** JSON-LD `CafeOrCoffeeShop` schema plus OpenGraph and Twitter cards. The metadata base URL in the code points to an older Vercel domain, which still needs updating to the live link.
