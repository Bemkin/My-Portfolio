### 🤖 Brain3 — Autonomous AI Purchasing Agent

**Brain3** is an enterprise-grade autonomous procurement agent designed to continuously audit inventory levels, predict stock depletion, generate AI-optimized purchase orders, and dispatch supplier emails without human intervention.

---

### 🌟 Key Architecture & Capabilities

1. **Dual-Node Operating System**:
   - **Auto-Pilot Mode (Zero Touch)**: Fully autonomous procurement. The AI agent audits stock, calculates optimal reorder quantities, generates POs, approves orders within threshold ceiling, and dispatches supplier emails automatically.
   - **Approval Mode (Human-in-the-Loop)**: AI generates draft PO recommendations with detailed reasoning, queuing them for human operator sign-off before dispatch.

2. **Gemini 3.5 Flash Lite + Zod Schema Validation**:
   - Consolidates low-stock inventory audit items into a single parallel batch request to Gemini `gemini-3.5-flash-lite`.
   - Enforces strict JSON schema validation via **Zod** (`BatchReorderResponseSchema`).

3. **Fail-Safe Mathematical Engineering**:
   - If Gemini API quota or network errors occur, the pipeline gracefully falls back to deterministic mathematical reorder engineering:
     $$ \text{Reorder Quantity} = \min\left((\text{Reorder Point} \times 2) - \text{Current Stock}, \, \text{Max Capacity} - \text{Current Stock}\right) $$
   - Guarantees zero system downtime and continuous business continuity.

4. **Executive Light Dashboard Aesthetic**:
   - Modern executive UI inspired by the Donezo Light SaaS dashboard.
   - Solid Forest Green (`#064e3b`), Emerald Green (`#059669`), Off-White canvas (`#f3f4f6`), and crisp white card containers.
   - `⌘F` / `Ctrl+F` global search shortcut, live instant search dropdown, supplier email logs popover, and system alerts notification drawer.
